# Working rules

Use English for source, comments, UI text, tests and documentation.
Keep acquisition and analysis separate. This project must not start captures,
connect to Ubuntu, or change source recordings. Raw data and participant
identifiers must not be committed. No commit, push or remote creation without
explicit authorization. Keep replay processing causal and test it for prefix
invariance. A periodic candidate is not proof of breathing or person presence.
Do not copy TI-device-restricted implementation code into this Intel CSI project.
